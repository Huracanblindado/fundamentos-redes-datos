netstat
Parámetro	Función y Uso Práctico
-d	Evita la resolución de nombres (DNS): Muestra únicamente las direcciones IP de cada salto sin intentar traducirlas a nombres de dominio (hostnames). Esto acelera significativamente la prueba.
-h saltos_máximos	Límite de saltos: Define la cantidad máxima de routers (saltos) que rastreará antes de detenerse (por defecto suele ser 30). Ejemplo: tracert -h 15 google.com limita la búsqueda a 15 saltos.
-j lista-host	Enrutamiento de origen relajado (Solo IPv4): Permite especificar una lista de nodos o routers intermedios por los que deseas que pase la ruta antes de llegar al destino.
-w tiempo_espera	Tiempo de espera (Timeout): Configura en milisegundos cuánto tiempo esperará una respuesta de cada router antes de dar un "tiempo de espera agotado" (*). Ejemplo: tracert -w 1000 8.8.8.8 establece el tiempo límite en 1 segundo.
-R	Ruta de retorno (Solo IPv6): Rastrea y muestra la ruta de regreso que toman los paquetes desde el destino hacia tu equipo.
-S srcaddr	Dirección IP de origen (Solo IPv6): Especifica cuál de tus direcciones IP locales utilizar para enviar los paquetes (útil cuando tu tarjeta de red tiene múltiples IP configuradas).
-4	Forzar IPv4: Obliga a la herramienta a realizar el rastreo únicamente a través de red IPv4, ignorando IPv6 aunque esté disponible.
-6	Forzar IPv6: Obliga a la herramienta a realizar el rastreo exclusivamente a través de red IPv6.
Casos de uso más comunes:

Diagnóstico rápido: Usa tracert -d <destino> para obtener una respuesta inmediata sin perder tiempo esperando la traducción de nombres DNS.

Redes lentas o lejanas: Usa tracert -w 3000 <destino> si estás diagnosticando una conexión satelital o muy lenta para evitar falsos "tiempos de espera agotados".

Elemento	Descripción y Función
nslookup	Comando ejecutado: Significa Name Server Lookup. Es una herramienta de consola utilizada para consultar los servidores DNS y verificar la resolución de nombres de dominio o direcciones IP.
Servidor predeterminado: dns.google	Nombre del servidor DNS activo: Indica el nombre del servidor al que tu equipo le hará las consultas DNS. En este caso, identifica al DNS público de Google.
Address: 8.8.8.8	Dirección IP del servidor DNS: Muestra la IP exacta del servidor DNS predeterminado que está respondiendo a la solicitud (en este caso, la IP primaria del DNS de Google).
>	Modo interactivo activo: Al presionar Enter tras escribir nslookup sin argumentos, la consola entra en modo interactivo. El cursor > indica que está listo para recibir comandos de consulta directos.
Principales funciones y comandos dentro del modo interactivo (>):

Consultar una dirección IP: Escribe cualquier dominio (ejemplo: google.com) y presiona Enter para obtener sus IP asociadas (Registros A/AAAA).

Búsqueda inversa: Escribe una dirección IP (ejemplo: 142.250.190.46) para averiguar a qué dominio pertenece (Registro PTR).

Cambiar tipo de registro (set type=):

set type=ns → Muestra los servidores de nombres autoritativos del dominio.

set type=txt → Muestra registros de texto (útil para validar SPF, DKIM o propiedad de un dominio).

Cambiar de servidor DNS (server): Permite hacer pruebas con otro servidor. Ejemplo: escribir server 1.1.1.1 cambia las consultas al DNS de Cloudflare.

Salir del modo interactivo: Escribe exit y presiona Enter para volver a la línea de comandos normal de Windows.

¿Qué es en realidad arp y para qué sirve?

El protocolo ARP (Address Resolution Protocol) es un comando del sistema operativo (que debe usarse directamente en la consola principal de Windows, no dentro de nslookup) para asociar direcciones IP con direcciones físicas de red (MAC Address).

¿Para qué se utiliza?

Mapeo de la red local: Mapea la dirección IP de un dispositivo en tu red local con su dirección MAC física (la dirección única de la tarjeta de red).

Diagnóstico de conflictos de IP: Permite verificar si dos equipos en la red local están usando por error la misma dirección IP.

Seguridad de red: Ayuda a detectar ataques de suplantación de identidad en la red local (conocidos como ARP Spoofing o ARP Poisoning).

Comandos útiles de ARP (para usar saliendo de nslookup con exit):

arp -a: Muestra la tabla de direcciones IP y sus correspondientes direcciones MAC guardadas en tu equipo.

arp -d *: Borra la caché ARP del sistema (útil para refrescar las conexiones si cambiaste de router o de IP).

¿Qué es realmente el comando route y para qué sirve?

El comando route es una herramienta de administración de red de la consola de Windows (CMD) que sirve para visualizar y manipular la tabla de enrutamiento IP del sistema operativo.

¿Para qué se utiliza?

Ver la tabla de enrutamiento: Muestra cómo el equipo decide por qué tarjeta de red o puerta de enlace (gateway/router) enviar el tráfico de datos según la IP de destino.

Añadir rutas estáticas: Permite redirigir manualmente el tráfico dirigido a una red o IP específica a través de un gateway distinto al predeterminado.

Eliminar o modificar rutas: Útil para solucionar problemas donde el tráfico no sale por la interfaz correcta (por ejemplo, al usar conexiones VPN o múltiples tarjetas de red).

Comandos útiles de route (ejecutándolos fuera de nslookup):

route print: Muestra toda la tabla de enrutamiento actual de tu equipo (interfaces, rutas IPv4 e IPv6 y la puerta de enlace predeterminada).

route add <IP_destino> mask <máscara> <gateway>: Agrega una nueva ruta manual a la tabla.

route delete <IP_destino>: Elimina una ruta específica de la tabla.

Nota: Para salir del modo interactivo de nslookup y poder usar route print, simplemente escribe exit y presiona Enter.

tracert
La imagen muestra la pantalla de ayuda del comando tracert en la consola de Windows (CMD), el cual sirve para rastrear la ruta que siguen los paquetes de datos desde tu equipo hasta un destino en la red.

Desglose del contenido:

Comando ejecutado (tracert): Al escribirlo solo (sin un destino como google.com), el sistema muestra el manual de uso.

Sintaxis de uso (Uso:): Muestra la estructura para ejecutar el comando con sus parámetros opcionales y el nombre_destino obligatorio al final.

Opciones (Parámetros principales):

-d: Evita traducir las direcciones IP a nombres de dominio (hace el rastreo más rápido).

-h saltos_máximos: Define el límite de routers ("saltos") por los que pasará la prueba antes de detenerse.

-j lista-host: Establece una ruta de origen relajada (exclusivo para IPv4).

-w tiempo_espera: Configura el tiempo de espera en milisegundos para la respuesta de cada salto.

-R / -S srcaddr: Opciones específicas para rastreo y origen en redes IPv6.

-4 / -6: Fuerza al comando a usar protocolo IPv4 o IPv6, respectivamente.
