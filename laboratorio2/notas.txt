net user
La imagen muestra la ejecución del comando net user en la consola de comandos de Windows (CMD). Este comando lista todas las cuentas de usuario registradas en el equipo.

Desglose línea por línea:

C:\Users\Dell> net user:
Es la instrucción ejecutada para solicitar la lista completa de usuarios locales del sistema.

Cuentas de usuario de \\DESKTOP-KTA9KTL:
Indica el nombre de la computadora (DESKTOP-KTA9KTL) a la cual pertenecen las cuentas listadas.

Explicación de las cuentas encontradas:

Administrador:
Es la cuenta integrada con privilegios elevados del sistema operativo. Por defecto viene deshabilitada en Windows por seguridad.

DefaultAccount:
Es una cuenta del sistema administrada por Windows que se utiliza para ejecutar ciertos procesos y aplicaciones del sistema en segundo plano.

Dell:
Es la cuenta de usuario principal activa (tu perfil de usuario actual), con la que iniciaste sesión y usas la computadora.

Invitado:
Es una cuenta integrada pensada para accesos temporales con permisos extremadamente reducidos. Por defecto también viene desactivada.

WDAGUtilityAccount:
Es una cuenta de servicio utilizada por Windows Defender Application Guard para ejecutar entornos de navegación y aplicaciones de forma aislada y segura dentro de un contenedor.

La cuenta expira (Nunca): No tiene una fecha límite programada para su desactivación automática.

Parámetros de contraseña y seguridad

La contraseña expira (Nunca): La clave no vence ni exige un cambio periódico.

El usuario puede cambiar la contraseña (Sí): Permisos otorgados para que el propio usuario modifique su clave cuando lo desee.

Restricciones de acceso y sesión

Estaciones de trabajo autorizadas (Todas): Permite iniciar sesión en cualquier computadora dentro del dominio o red local.

Script de inicio de sesión (Vacío): No ejecuta ningún archivo o script automatizado al iniciar sesión.

Última sesión iniciada (21/8/2026 2:01:05 p. m.): Registro del momento exacto en que ingresó al equipo por última vez.

Horas de inicio de sesión autorizadas (Todas): No posee restricciones de horario; se puede usar la cuenta a cualquier hora.

Grupos y permisos de red

*Miembros del grupo local (Administradores): La cuenta pertenece al grupo con control total sobre la máquina.

*Miembros del grupo global (Ninguno): No está asignada a ningún grupo dentro de un dominio empresarial de Windows.

Error de sistema 5.:
Es un código de error nativo de Windows que significa técnicamente "Acceso denegado" (Access Denied).

Acceso denegado.:
El mensaje explícito del sistema indicando que la instrucción no se pudo completar. Esto ocurre porque la consola de comandos se abrió como un usuario estándar o sin privilegios elevados.

¿Cómo solucionarlo?

Para crear usuarios o realizar modificaciones del sistema, debes ejecutar la consola como Administrador:

Cierra la ventana actual de CMD.

En el menú de inicio de Windows, busca "cmd" o "Símbolo del sistema".

Haz clic derecho sobre el ícono y selecciona Ejecutar como administrador.

Vuelve a ingresar el comando.

net user dell active yes

1. La ruta del directorio (C:\Windows\system32>)

2. El comando (net user dell /active:yes)

/active:yes: El parámetro que le indica a Windows que debe activar u habilitar esa cuenta. Si la cuenta estaba suspendida, bloqueada o deshabilitada, este comando le devuelve el acceso completo para iniciar sesión.

Windows procesó la instrucción sin errores y aplicó el cambio de inmediato.
