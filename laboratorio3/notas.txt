net localgroup
La imagen muestra la ejecución del comando net localgroup en la consola de comandos de Windows (CMD) dentro del equipo local llamado DESKTOP-KTA9KTL. Este comando sirve para listar todos los grupos locales de usuarios existentes en el sistema operativo.

Desglose de la imagen

El Comando (net localgroup): Instrucción de red y administración que le pide a Windows mostrar la base de datos de grupos de seguridad de la máquina local.

Encabezado (Alias para \\DESKTOP-KTA9KTL): Indica el nombre de red del equipo donde se están consultando los grupos.

La Lista (marcada con *): Cada elemento precedido por un asterisco es un grupo de seguridad predeterminado o creado en Windows.

Explicación de los grupos principales

Grupo	Función principal
Administradores	Tienen acceso total y control ilimitado sobre el equipo y el sistema operativo.
Usuarios	Usuarios estándar; pueden ejecutar programas y realizar tareas comunes, pero no modificar el sistema.
Invitados	Cuentas con permisos muy reducidos para accesos temporales.
Usuarios avanzados	Grupo heredado de versiones antiguas de Windows con permisos intermedios entre usuario y administrador.
Usuarios de escritorio remoto	Permite a sus miembros iniciar sesión en el equipo a través de una conexión RDP (Escritorio Remoto).
Operadores de copia de seguridad	Permite a los usuarios realizar e identificar copias de respaldo del sistema sin necesidad de permisos de administrador.
IIS_IUSRS	Grupo utilizado por el servidor web local de Windows (Internet Information Services) para ejecutar aplicaciones web.
Administradores de Hyper-V	Otorga permisos para administrar máquinas virtuales creadas con Hyper-V.
Comandos útiles relacionados

Si quieres ver qué usuarios pertenecen a un grupo específico (por ejemplo, para ver quién es administrador), ejecuta:

DOS
net localgroup Administradores
Si deseas agregar un usuario existente a un grupo:

DOS
net localgroup Administradores nombre_usuario /add

net localgroup Administradores 
La imagen muestra la ejecución del comando net localgroup Administradores en la consola de Windows (CMD). Este comando se utiliza para inspeccionar los miembros de un grupo específico, en este caso, del grupo privilegiado "Administradores".

Desglose línea por línea

net localgroup Administradores: Es la instrucción ejecutada. Al agregar el nombre de un grupo al final, le pides a Windows que muestre los detalles y los integrantes de ese grupo en particular.

Nombre de alias: Administradores: Confirma el grupo que estás consultando.

Comentario: Los administradores tienen acceso completo...: Una breve descripción oficial del sistema sobre las capacidades de este grupo (control total del equipo).

Miembros: Es la sección principal que lista las cuentas de usuario o de sistema que pertenecen a este grupo.

Análisis de las cuentas listadas

Administrador: Es la cuenta local nativa integrada de Windows (Built-in Administrator). Viene creada por defecto en el sistema operativo, aunque habitualmente permanece deshabilitada por motivos de seguridad a menos que se active manualmente.

Dell: Es la cuenta de usuario principal activa en este equipo. Al estar listada aquí, significa que este usuario tiene privilegios elevados de administrador (puede instalar programas, modificar la configuración del sistema, editar el registro, etc.).

Comandos útiles relacionados

Para añadir un usuario a este grupo:

DOS
net localgroup Administradores NombreUsuario /add
Para quitar un usuario de este grupo:

DOS
net localgroup Administradores NombreUsuario /delete

net localgroup Proyect add
El comando net localgroup Proyectos /add sirvió para crear un grupo local totalmente nuevo llamado Proyectos en el sistema operativo.

Desglose del comando término a término

net: La herramienta ejecutable principal de Windows para gestionar servicios, cuentas de red y recursos del sistema desde la consola.

localgroup: La subfunción del comando net que especifica que la acción se aplicará sobre los grupos locales de la máquina.

Proyectos: El nombre asignado al nuevo grupo que acabas de crear.

/add: El parámetro o modificador que le indica a Windows que debe añadir/crear ese grupo en la base de datos de seguridad local.

Resultado y utilidad

El mensaje "Se ha completado el comando correctamente." confirma que el grupo se registró en el equipo. Crear grupos personalizados como este es fundamental para:

Organizar permisos: Asignar accesos a carpetas o archivos compartidos a todo un equipo de trabajo de un solo golpe.

Gestión centralizada: En lugar de darle permisos usuario por usuario, agregas los usuarios al grupo Proyectos y le das los permisos únicamente a ese grupo.

Siguientes pasos útiles

Para agregar un usuario (por ejemplo, Dell) a tu nuevo grupo:

DOS
net localgroup Proyectos Dell /add
Para eliminar el grupo si ya no lo necesitas:

DOS


net localgroup Proyectos /delete

El comando net localgroup Proyectos /delete sirve para eliminar de forma permanente un grupo local creado previamente en el sistema operativo.

Desglose término a término

net: La herramienta de comandos de Windows para administrar redes, usuarios y servicios del sistema.

localgroup: Indica que la instrucción actuará sobre la base de datos de grupos locales de la máquina.

Proyectos: El nombre del grupo objetivo que se va a borrar.

/delete: El parámetro o bandera que le ordena a Windows destruir/eliminar dicho grupo.

Puntos clave sobre este comando

¿Qué elimina y qué no?: Solo elimina la estructura del grupo "Proyectos". No borra las cuentas de usuario que pertenecían a él; esas cuentas siguen existiendo de forma individual en el sistema.

Permisos asociados: Si este grupo tenía permisos asignados a carpetas o archivos compartidos, esos accesos vinculados al grupo quedan revocados de inmediato.

Confirmación: El mensaje "Se ha completado el comando correctamente." indica que la eliminación se realizó con éxito y el grupo ya no aparecerá en la lista al ejecutar net localgroup.
